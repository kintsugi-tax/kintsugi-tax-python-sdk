## list

The Get Transactions API retrieves a list of transactions with
    optional filtering, sorting, and pagination.

### Example Usage

<!-- UsageSnippet language="python" operationID="get_transactions_v1_transactions_get" method="get" path="/v1/transactions" -->
```python
from kintsugi_tax_platform_sdk import SDK


with SDK(
    api_key_header="<YOUR_API_KEY_HERE>",
) as sdk:

    res = sdk.transactions.list(x_organization_id="org_12345", address_status_in="UNVERIFIED,INVALID,PARTIALLY_VERIFIED,VERIFIED,UNVERIFIABLE", order_by="date,state,customer_name,status", connection_id_in="conn_abc123,conn_def456", page=1, size=50)

    # Handle response
    print(res)

```

## create

Create a transaction. Set `marketplace: true` for reseller or marketplace orders where tax was remitted externally; gross sales still count toward nexus, but tax liability is excluded.

### Example Usage: connection_mismatch

<!-- UsageSnippet language="python" operationID="create_transaction_v1_transactions_post" method="post" path="/v1/transactions" example="connection_mismatch" -->
```python
from kintsugi_tax_platform_sdk import SDK, models
from kintsugi_tax_platform_sdk.utils import parse_datetime


with SDK(
    api_key_header="<YOUR_API_KEY_HERE>",
) as sdk:

    res = sdk.transactions.create(x_organization_id="org_12345", organization_id="<id>", external_id="<id>", date_=parse_datetime("2025-11-05T23:48:53.053Z"), addresses=[], transaction_items=[], customer={
        "organization_id": "<id>",
        "is_test_data": False,
    }, type_=models.TransactionTypeEnum.ARCHIVE, locked=False)

    # Handle response
    print(res)

```

## set_transaction_tax_only_v1_transactions_transaction_id_tax_only_post
